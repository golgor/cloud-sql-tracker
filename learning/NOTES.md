# Working Notes & Teaching Preferences

- **Target Audience**: Competent Rust developer with basic language fluency (ownership, `Result`, traits, `match`), but ZERO prior context on this project, Cloud SQL, systemd, or D-Bus.
- **Teaching Style**: Big picture first, gradually zooming into specific files, types, and functions. Code-heavy explanations with verbatim snippets and precise `src/file.rs:line` citations.
- **Pedagogy**: Tufte-style clean HTML lessons with 3 retrieval-practice questions per chapter to build storage strength.
- **Model Preference for Subagents**: Use `gemini-3.7-flash` for subagents to avoid Claude rate-limit issues.
