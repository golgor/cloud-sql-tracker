Quick Reference

Cheat Sheet

Comprehensive operator and developer quick reference: subcommands, exit codes, health states, preflight checks, module boundaries, system paths, and release workflows.

1. Subcommands & Argv Syntax

Global flags: --config PATH, -h / --help, -V / --version (prints bare semver). Mass mutations require an explicit target (ID, --group NAME, or --all); target selectors are mutually exclusive.

Subcommand Argv Signature Default Target Key Options Purpose & Output
status status [--json] [ID | --group G | --all] --all --json Inspects systemd and TCP sockets via Reconcile. Emits human table or machine Status document (v1 schema).
start start <ID | --group G | --all> Required --wait-ms <ms> (10000) Spawns transient user units (Type=exec) via D-Bus; polls up to --wait-ms until TCP port accepts.
stop stop <ID | --group G | --all> Required --wait-ms <ms> (10000) Stops transient user units via D-Bus; cleans up failed state; polls until unit is absent and port is closed.
restart restart [--failed] <ID | --group G | --all> Required --failed, --wait-ms <ms> Stops then starts targets. With --failed, filters batch to only connections currently in Health state error.
logs logs <ID> [-n <lines>] Single ID only -n <lines> (100) Dumps captured systemd user journal entries for the connection's unit using journalctl in ISO timestamp format.
doctor doctor [--json] Entire host --json Runs six preflight checks (config, proxy binary version probe, systemd D-Bus, ADC, journald, port conflicts).

2. Process Exit Codes

Multi-target mutations are not transactional: successes stay running on partial failures. Exit code reflects overall batch outcome.

Code Name Classification Rules Concrete Examples
0 Success All requested operations succeeded, or idempotent no-op (e.g. starting an already-running connection, stopping an already-stopped connection, restart --failed with 0 failed units, or status completed). start --all (7/7 ok); start fe-dev (already running); logs fe-dev (empty or non-empty journal).
1 Partial Failure Multi-target batch where at least one target succeeded and at least one target failed. Survivors remain in their new state. (Never emitted by single-ID commands or logs). start --all (6 connections started successfully, 1 failed to bind port).
2 Usage / Config Error Invalid command-line arguments, unknown flags, missing target selector on mutate, conflicting selectors (e.g. fe-dev --all), unknown connection ID/group, targeting a disabled ID, or invalid/unparseable config JSON. start (missing target); start unknown-id; connections.json containing unknown keys; logs -n 0.
3 Dependency Error Environmental / external failure preventing whole-command execution: D-Bus systemd user bus unreachable, ADC credentials missing/unreadable, proxy binary unresolvable on start, or journalctl missing from PATH. start --all when systemd --user is down; doctor with broken ADC; logs fe-dev without journalctl.
4 Total Failure Every attempted target in a multi-target batch failed, or a single-ID mutating operation failed during execution. start fe-dev (port conflict with foreign process); start --group backend (0/2 connections succeeded).

3. Health States & Error Classifications

Produced deterministically by reconcile() from systemd unit state, start timestamp, TCP port liveness, and listener PID attribution.

Health State Source Unit ActiveState TCP Probe Evaluation Logic & Error Code
stopped none inactive / absent Closed Unit is absent or cleanly stopped (exited with code 0 or 143 / SIGTERM); local port is closed.
starting unit activating / active Closed Unit is activating or active, but age is within START_WINDOW (10,000 ms) and TCP port has not opened yet.
running unit active / activating Open TCP socket accepts connections and listener PID matches unit MainPID (or probe cannot inspect foreign PID).
error unit active / failed Closed start_timeout (active >10s but port still closed), unit_failed (crashed / non-143 exit), or exec_failed.
error none inactive / absent Open port_in_use — Local port held by a foreign process (Docker, local DB, unmanaged proxy) while unit is stopped.
error none active Open (mismatch) port_in_use — Port held by a PID different from unit's MainPID (conflict with another process).

4. Doctor Preflight Checks (Catalog Order)

cloud-sql-tracker doctor [--json] evaluates host health in fixed sequence. Invariant: ok === true if and only if zero checks fail.

Order Check ID Severity Target / Resource Probed Pass Condition (Hard vs Warn)
1 config Hard (fail) connections.json (XDG or --config) File exists, is readable, valid JSON, version 1, no unknown keys, unique IDs/ports/instances, no reserved ports.
2 proxy_bin Hard (fail) cloud-sql-proxy executable path Resolves on PATH / config path, is executable, and running <path> -v exits 0 with cloud-sql-proxy version <token> within 2s.
3 systemd_user Hard (fail) org.freedesktop.systemd1 on user bus D-Bus user session bus reachable at $XDG_RUNTIME_DIR/bus; systemd responds to manager version query.
4 adc Hard (fail) Google Application Default Credentials $GOOGLE_APPLICATION_CREDENTIALS file exists, or default ~/.config/gcloud/application_default_credentials.json exists.
5 journal_user Hard (fail) User systemd journal via journalctl journalctl exists on PATH and journalctl --user -n 0 --no-pager executes with zero exit status.
6 ports Warn only TCP listeners on all connection ports pass if all configured ports are closed or held by our unit; warn if any port is held by a foreign PID.

5. Architecture & Module Map

Strict acyclic dependency graph: reconcile depends only on model. Adapters isolate OS I/O behind clean value types.

Module Path Type Architectural Role Key Public Functions / Types
src/main.rs I/O Thin binary entry point. fn main() -> ! (invokes std::process::exit(cli::run())).
src/cli.rs I/O Clap CLI parsing, stdout/stderr formatting, exit code mapping. pub fn run() -> i32, struct Cli, enum Commands.
src/commands/select.rs Pure Target selector expansion & error filtering. pub fn resolve_targets(), enum TargetSelector, struct TargetConnection.
src/commands/status.rs I/O + Pure Assembles runtime observations into StatusDocument. pub fn status(), fn assemble_document(), fn format_rfc3339().
src/commands/mutate.rs I/O Start, stop, restart batch orchestration & polling loops. pub fn start(), pub fn stop(), pub fn restart(), struct BatchOutcome.
src/commands/doctor.rs I/O Runs and aggregates the six preflight check rows. pub fn doctor() -> DoctorReport, fn ports_check().
src/commands/logs.rs I/O Single connection unit resolution & journal dump. pub fn logs().
src/reconcile.rs Pure Pure decision engine; maps observations to HealthState. pub fn reconcile() -> StatusRowFields, const START_WINDOW: Duration.
src/model.rs Pure Domain types, DTO wire structs, unit name sanitization. struct Connection, enum HealthState, enum Source, fn unit_name().
src/config.rs I/O + Pure JSON parsing, defaults merging, strict validation. pub fn parse() (pure), pub fn load() (I/O), struct Config.
src/supervisor.rs I/O Systemd user manager D-Bus client via zbus. pub fn start_transient(), pub fn stop(), pub fn show(), enum UnitSnapshot.
src/port.rs I/O TCP socket connect probe & procfs PID attribution. pub fn observe() -> PortObservation, enum PortProbe (Open/Closed/Unreachable).
src/env/mod.rs I/O PATH binary discovery & local ADC credential check. pub fn resolve_proxy_bin(), pub fn proxy_bin_check(), pub fn adc_check().
src/env/version_probe.rs I/O + Pure Spawns proxy with -v, bounds wait, parses version token. pub fn probe_proxy_version(), fn parse_proxy_version_output() (pure).
src/journal.rs I/O Spawns journalctl to dump logs and check user journal. pub fn dump() -> Result<Dump, JournalError>, pub fn journal_user_check().

6. Port Allocation & Reservation Rules

Enforced strictly during config::parse(). Invalid port numbers cause immediate config rejection (Exit 2).

Port Range / Number Category Status Reason & Enforcement
1 – 1023 Privileged Ports Forbidden Requires root / CAP_NET_BIND_SERVICE. CLI runs strictly as an unprivileged user process.
5432 Standard PostgreSQL Forbidden Prevents collisions with local PostgreSQL instances or Docker Compose sidecars.
3306 Standard MySQL Forbidden Prevents collisions with local MySQL / MariaDB developer containers.
1433 Standard MS SQL Server Forbidden Prevents collisions with local SQL Server instances.
1024 – 65535 (excl. 1433/3306/5432) Unprivileged Ports Allowed Valid connection bind target. Must be uniquely assigned across all connections in config.
15432 – 15438 Golden Config Range Standard Default range used in examples/connections.json across backend, frontend, and IoT groups.

7. Key System & Runtime Paths

Path / Location Associated Component Persistence & Lifetime Description & Purpose
~/.config/cloud-sql-tracker/connections.json config adapter Permanent (User disk) Default config file path (overridden by $XDG_CONFIG_HOME or --config PATH).
~/.config/gcloud/application_default_credentials.json env::adc check Permanent (User disk) Default ADC credentials file created by gcloud auth application-default login.
/run/user/<UID>/bus supervisor adapter Login Session (tmpfs) D-Bus user session socket used by zbus to control systemd --user.
/run/user/<UID>/systemd/transient/cloud-sql-proxy-<ID>.service systemd --user Volatile (Memory / tmpfs) Dynamic transient unit definition. Automatically discarded at poweroff or logout.
/proc/net/tcp & /proc/net/tcp6 port adapter Kernel runtime Scanned by procfs to detect listening TCP socket inodes.
/proc/<PID>/fd/ & /proc/<PID>/comm port adapter Kernel runtime Inspected to match socket inodes with owning process PIDs and executable names.
~/.local/bin/cloud-sql-tracker Developer install Symlink / Binary Standard user binary location created by mise run install-local.

8. Developer & CI Commands (Mise)

Mise tasks provide thin, auditable wrappers around standard Cargo commands and repo validation scripts.

Mise Command Underlying Execution Purpose & Scope
mise run check fmt-check + lint + test + contracts Full local gate matching GitHub Actions CI exactly. Run before every push.
mise run fmt cargo fmt Formats all Rust source files according to rustfmt.toml.
mise run fmt-check cargo fmt --check Non-mutating verification of Rust source formatting.
mise run lint cargo clippy --all-targets --all-features -- -D warnings Clippy linter execution with all warnings denied as errors.
mise run test cargo test Runs all 265+ unit and integration tests (never passes --include-ignored).
mise run contracts scripts/validate-contracts.sh Layer 1 contract verification: validates golden JSON files against JSON Schemas.
mise run build-release cargo build --release --locked Compiles optimized release binary with LTO, 1 codegen unit, and symbol stripping.
mise run install-local build-release + ln -sfn ... ~/.local/bin/cloud-sql-tracker Builds release binary and refreshes local symlink for PATH dogfooding.

9. Release Cutting Checklist (Sequential)

Follow these steps in strict sequence to publish a new official GitHub Release and binary artifact:

Step Action Exact Command / File Target Verification & Invariant
1 Verify local gate mise run check All formatting, clippy, unit tests, and Layer 1 contract checks must pass with exit 0.
2 Bump version in manifest Cargo.toml → edit version = "X.Y.Z" Cargo.toml is the single source of truth for version identity.
3 Regenerate lockfile cargo check or cargo build Mandatory in same commit: Updates Cargo.lock root package version to prevent --locked CI failure.
4 Update docs & goldens README.md, examples/doctor.v1.json Update golden examples and documentation version headers if semver changed.
5 Commit release prep git commit -am "release: bump package version to X.Y.Z" Pre-commit and pre-push hk hooks run automated checks.
6 Create annotated tag git tag -a vX.Y.Z -m "vX.Y.Z" Tag must be prefixed with v followed by exact Cargo.toml semver string.
7 Push branch and tag git push origin main && git push origin vX.Y.Z Triggers .github/workflows/release.yml to build, package .tar.gz, compute SHA256SUMS, and publish GitHub Release.
